# CS:GO Steam Reviews — Exploratory Data Analysis

## Deskripsi Proyek
Proyek ini bertujuan untuk melakukan Exploratory Data Analysis (EDA) terhadap dataset ulasan pemain Counter-Strike: Global Offensive (CS:GO) di Steam. Analisis dilakukan untuk memahami pola ulasan pemain melalui statistik deskriptif, tabel, dan visualisasi data.

## Tujuan Analisis
- Memahami struktur dan kualitas dataset.
- Menganalisis distribusi ulasan positif dan negatif.
- Mengeksplorasi hubungan waktu bermain dengan rekomendasi pemain.
- Menganalisis jumlah upvote, bahasa ulasan, dan status pembelian.
- Melihat distribusi variabel numerik serta korelasi antarvariabel.

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Temuan Utama
- Dataset berisi 15.640 baris dan 16 kolom.
- Sebanyak 89,38% ulasan dikategorikan positif berdasarkan kolom `voted_up`.
- Sebanyak 85,98% ulasan belum mendapatkan upvote.
- Korelasi antara jumlah upvote dan jumlah komentar tergolong kuat pada dataset ini.
